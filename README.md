# Omarchy Giants Theme

Standing on the shoulders of giants. A warm, low-contrast dark theme for
[Omarchy](https://omarchy.org) built around ink on aged paper: sepia and cream
foregrounds over a soft brown-black background, with a dusty terracotta accent.

![Giants preview](preview.png)

## Giants

The collection features 32 influential computer scientists and their main
contributions:

| Giant | Main contribution |
| --- | --- |
| Charles Babbage | Designed the Difference Engine and Analytical Engine; established early concepts of programmable computing. |
| Ada Lovelace | Wrote the first algorithm intended for a machine and recognized computing’s broader potential. |
| John von Neumann | Developed the stored-program architecture and helped design early electronic computers. |
| Alan Turing | Founded the theory of computation with the Turing machine and contributed to codebreaking and early AI. |
| Claude Shannon | Founded information theory and connected Boolean algebra with digital circuits. |
| Grace Hopper | Developed early compilers and helped create COBOL. |
| John Backus | Led the creation of FORTRAN and developed Backus–Naur Form. |
| Peter Naur | Contributed to ALGOL 60, Backus–Naur Form, and compiler techniques. |
| Ken Iverson | Invented APL and pioneered concise array-programming notation. |
| Edsger Dijkstra | Advanced structured programming, shortest-path algorithms, concurrency, and software correctness. |
| Donald Knuth | Established modern algorithm analysis and created TeX and literate programming. |
| C. A. R. Hoare | Created Quicksort, Hoare logic, and Communicating Sequential Processes. |
| Niklaus Wirth | Designed Pascal, Modula, and Oberon with an emphasis on simplicity and structured programming. |
| Margaret Hamilton | Led Apollo Guidance Computer software and pioneered rigorous software engineering for mission-critical systems. |
| Barbara Liskov | Developed CLU, abstract data types, the Liskov substitution principle, and fault-tolerant systems research. |
| Alan Kay | Created Smalltalk and pioneered object-oriented programming and personal-computer concepts. |
| Dennis Ritchie | Created C and co-developed Unix. |
| Brian Kernighan | Shaped Unix tools and software culture; co-authored *The C Programming Language*. |
| Ken Thompson | Co-created Unix, invented B, and contributed to UTF-8 and Go. |
| Andrew S. Tanenbaum | Designed MINIX and shaped operating-systems education through influential textbooks. |
| Leonard Adleman | Co-invented RSA public-key cryptography and pioneered DNA computing. |
| Ronald Rivest | Co-invented RSA and developed influential cryptographic algorithms. |
| Adi Shamir | Co-invented RSA and advanced secret sharing and zero-knowledge proofs. |
| Bjarne Stroustrup | Designed and implemented C++. |
| Guido van Rossum | Created the Python programming language. |
| Yukihiro Matsumoto | Created the Ruby programming language. |
| John McCarthy | Created Lisp and helped establish artificial intelligence as a field. |
| James Gosling | Created the Java programming language. |
| Brendan Eich | Created JavaScript and helped shape browser scripting. |
| Tim Berners-Lee | Invented the World Wide Web, including HTTP, HTML, and URLs. |
| Anders Hejlsberg | Designed Turbo Pascal, Delphi, C#, and TypeScript. |
| Linus Torvalds | Created the Linux kernel and initiated Git. |

The wallpapers use the same aged-paper, monochrome ink, technical-diagram,
and terracotta-accent treatment as the original. Research notes, source
portrait credits, licenses, and generation details are in
[CREDITS.md](CREDITS.md).

## Install

```bash
omarchy theme install https://github.com/dhh/omarchy-giants-theme
```
